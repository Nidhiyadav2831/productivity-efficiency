# Productivity & Efficiency Analyzer

A full-stack productivity management platform that helps users track tasks, monitor productivity, set goals, and analyze performance through interactive dashboards and analytics.

## Features

* User Authentication (Login & Signup)
* Task Management System
* Goal Tracking
* Productivity Analytics Dashboard
* Time Tracking
* User Profile Management
* Responsive UI with Modern Design
* Secure Backend APIs

## Tech Stack

### Frontend

* React.js
* Vite
* Tailwind CSS
* JavaScript

### Backend

* Node.js
* Express.js
* MongoDB
* JWT Authentication


## Installation

### Clone Repository

```bash
git clone https://github.com/Nidhiyadav2831/productivity-efficiency.git
cd productivity-efficiency
```

### Install Dependencies

```bash
cd backend
npm install

cd ../frontend
npm install
```

### Run Backend

```bash
cd backend
npm start
```

### Run Frontend

```bash
cd frontend
npm run dev
```
